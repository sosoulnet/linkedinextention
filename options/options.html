How it works

  1. Set up your API key using the toolbar icon or this settings page
  2. Navigate to any LinkedIn profile page
  3. Click the blue chat icon in the bottom-right corner of the page
  4. Select the message tones you want
  5. Optionally add context about why you're reaching out
  6. Click "Generate Messages" to get personalized options
  7. Copy a message or insert it directly into the LinkedIn chat

Available Tones

  • Friendly - Warm, casual, approachable
  • Professional - Formal, business-oriented, polished
  • Question - Opens dialogue with an engaging question
  • Complimentary - Genuine praise for their work
  • Networking - Building mutual connections
  • Collaboration - Proposing to work together
